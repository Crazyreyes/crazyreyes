## Projects

### 🐍 Snake DQN
*Training an AI agent to play Snake*

An implementation of Deep Q-Learning where an agent learns to play Snake through repeated interaction with a custom game environment.

- Developed the game environment using Pygame
- Implemented a DQN model using PyTorch
- Applied experience replay and mini-batch training
- Evaluated performance over 100 episodes

| Evaluation metric | Score |
|---|---:|
| Average | 44.81 |
| Median | 45.5 |
| Best | 71 |
| Worst | 19 |

[View source code](https://github.com/Crazyreyes/snake-dqn)
